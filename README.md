# 机忆新生

国货运动时期工业产品类型交互可视化设计，以《机联会刊》广告中的产品为例。

本网站整理1930—1937年的3,952张广告图像，覆盖172个年份与期号组合、20个一级门类。6,142条分类标注项包括实物产品、非实物商品和其他分类，不代表不同商品种类的数量。

## 浏览方式

- 封面拼贴：浏览20个一级门类的代表广告图像。
- 时间总览：按年份、期号和页码查看广告，支持拖动与缩放。
- 分类、材料和生活用途筛选：匹配广告保持原位高亮。
- 年度比较：比较产品提及数或去重后的广告图片数。
- 图谱模式：依次展开产业、二级类别、具体产品、年份期刊和广告图片。
- 原图详情：查看对应产品标注、材料、用途及可确认的品牌和企业。

## 技术与部署

纯HTML、CSS和JavaScript静态网站，无需编译或第三方运行库。数据为`data.json`，网页广告图像在`images/`，缩略图图集在`atlases/`。

GitHub Pages使用`main`分支的根目录发布，`.nojekyll`用于跳过Jekyll处理。

本地预览可在本目录运行：

```bash
python3 -m http.server 8765
```

然后在浏览器访问`http://127.0.0.1:8765/`。
